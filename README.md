# AlimentaMais

Nosso app conecta doadores de alimentos a ONGs e iniciativas sustentáveis.

Aplicativo mobile em **React Native + Expo**, com autenticação (e-mail e Google) e dados no **Firebase**.

## Como rodar localmente

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o app:

   ```bash
   npx expo start
   ```

   No terminal aparecem as opções para abrir no [Expo Go](https://expo.dev/go), no
   [emulador Android](https://docs.expo.dev/workflow/android-studio-emulator/) ou no
   [simulador iOS](https://docs.expo.dev/workflow/ios-simulator/).

O projeto usa [roteamento por arquivos](https://docs.expo.dev/router/introduction): as telas ficam em `app/`.
